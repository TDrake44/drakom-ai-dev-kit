# .ai Directory

This directory is the canonical, tool-agnostic context center for AI-assisted development.

The included rules are starter defaults. Projects may edit, replace, or remove
them as long as `AGENTS.md` and any skill references remain accurate.

## Structure
- `rules/` - Declarative rules loaded on-demand by task type
- `plans/` - Local-only gitignored planning scratchpads
- `specs/` - Git-tracked specifications elevated for multi-dev collaboration
- `assets/` - Local-only reference assets (screenshots, logs, mockups)
- `mcp-servers.yaml` - Single source of truth for MCP server configuration
