# Project Rules

This folder contains stable, project-specific policies that affect implementation decisions.

Use `$drakom-ai-setup` to assess the repository and recommend rules such as
`coding.md`, `testing.md`, or `documentation.md` only when they are supported by
project evidence and approved by the project owner.

Avoid copying generic conventions here when the project's formatter, linter,
type checker, or tests already make them clear.
