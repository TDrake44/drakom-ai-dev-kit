# Project Rules

This folder contains stable, project-specific policies that affect implementation decisions.

Add a rule only when repository evidence shows a stable policy that tooling does
not enforce and the project owner approves it. Use `$drakom-ai-setup` to assess
the repository and decide what, if anything, belongs here; name each rule by its
scope.

Avoid copying generic conventions here when the project's formatter, linter,
type checker, or tests already make them clear.
