# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of
`@drakom/ai-dev-kit`.

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/TDrake44/drakom-ai-dev-kit/security/advisories/new) to report a suspected vulnerability.

Do not report vulnerabilities through public issues, discussions, pull requests,
or social media. Include a clear description, affected version, reproduction
steps, and potential impact. Do not include live credentials or other sensitive
data in a report.

We review reports as capacity allows and do not guarantee a specific response
time. Once reviewed, we will acknowledge receipt and coordinate a fix and
disclosure timeline with you.
