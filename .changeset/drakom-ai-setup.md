Reworks the `drakom-ai-setup` skill for installs with `npx skills add TDrake44/drakom-ai-dev-kit`, with no CLI. It creates only what is missing of `.drakom-ai/`: its `.gitignore`, a `rules/README.md` and a `specs/README.md`. The rules README says any rule file can go in `.drakom-ai/rules/`, keeps an empty "Topic rules" list for routing them, and describes the six optional extension files the skills find by name (`verification.md`, `review.md`, `plan.md`, `dev.md`, `pr.md` and `handoff.md`). Everything else is an offer, written only on your yes and never committed: an `AGENTS.md`, a pointer line to the rules, `.worktreeinclude` for the ignored plans and assets, the starter pull request template or its risk section, a route for each unrouted rule file, and the facts it finds kept elsewhere. It names the repo's own skills that overlap a kit skill for you to settle. Later runs offer a rules audit, and `drakom-ai-setup audit` runs only that: a read-only report in chat on broken routes, duplicate or conflicting rules, rules tooling already enforces and findings reviews repeated. `drakom-pr` now puts an added `## Risk` block, or the risk result when the template has no place for it, at the top after any opening comment, and records the template answer as `PR template offer: yes` or `PR template offer: no`. Until 0.7.0, the copy of setup the CLI installs lacks the files the new skill reads.
