# Changesets

Hello and welcome! This folder contains Changeset files. A changeset is a piece of information about a change made to a package, including the packages that changed and the summary of the changes.

When you make a pull request, you should add a changeset file by running:

```bash
pnpm changeset
```

You can read more about changesets at [https://github.com/changesets/changesets](https://github.com/changesets/changesets).
